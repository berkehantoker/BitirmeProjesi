Bireylerin siber güvenlik farkındalığını ölçmek ve kişiselleştirilmiş gelişim raporları sunmak amacıyla "Siber Suç Farkındalık Ölçeği (CAS) Dijital Platformu"nu full-stack olarak uçtan uca geliştirdim. Projede ayrık (decoupled) N-Katmanlı (N-Tier) mimari yaklaşımı benimseyerek, sunucu tarafında ASP.NET Core 8.0 Web API, istemci tarafında React.js ve veritabanı yönetiminde Entity Framework Core (Code-First) ile MS SQL Server teknolojilerini kullandım. Güvenli oturum yönetimi için JWT tabanlı kimlik doğrulama mekanizmasını entegre ettim. Klasik statik anket yapılarından farklı olarak, ters madde (reverse scoring) hesaplamalarını arka planda matematiksel olarak işleyen ve bu sayısal verileri OpenAI API (GPT-4o mini) üzerinden işleyerek NIST ve ISO 27001 standartlarına uygun kişiye özel uzman tavsiye raporları üreten bir "Hibrit Analiz Motoru" kurguladım. Front-end tarafında sayfalama ve Likert ölçeği altyapısını kurmanın yanı sıra, test sonuçlarını Chart.js aracılığıyla Radar ve Sütun grafikleriyle görselleştirdim. Son olarak, akademik veri toplama süreçleri için sistem genelindeki analizlerin Excel (CSV) formatında dışa aktarılabildiği ve risk dağılımlarının canlı olarak takip edilebildiği kapsamlı bir Admin (Yönetim) Paneli kodladım.
